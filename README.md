## 📖 About the Project

**HarmonyHome** is a full-stack e-commerce application dedicated to interior decoration and furniture.

The platform offers users a curated selection of furniture and decorative items, allowing them to discover products, explore different categories and create their own wishlist.

The project aims to provide a smooth and enjoyable shopping experience through an elegant interface, combining functionality, usability and a carefully designed visual identity.

The application was designed in Figma and developed using Angular, Node.js, Express.js and PostgreSQL.

## 🏗️ Application Architecture

HarmonyHome follows a client-server architecture.

The Angular frontend communicates with the Express.js backend through HTTP requests. The backend handles API routes, controllers and services, while TypeORM manages communication with the PostgreSQL database.

```text
          CLIENT
            |
            v
     ANGULAR FRONTEND
            |
       HTTP REQUESTS
            |
            v
      EXPRESS.JS API
            |
       ROUTES
            |
            v
       CONTROLLERS
            |
            v
        SERVICES
            |
            v
          TYPEORM
            |
            v
       POSTGRESQL
```

## 🗄️ Database Design

The application uses PostgreSQL to store and manage its data.

The database structure includes the following main entities:

- User
- Address
- Category
- SubCategory
- Product
- Wishlist
- Order
- OrderProduct

The database was modelled using conceptual, logical and physical data models (MCD, MLD and MPD).

## 🚀 Getting Started

Follow these steps to run HarmonyHome locally.

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Angular CLI
- PostgreSQL
- Git

### 1. Clone the Repository

```bash
git clone <YOUR_REPOSITORY_URL>
cd HarmonyHome
```

### 2. Install Frontend Dependencies

```bash
cd frontend
npm install
```

### 3. Install Backend Dependencies

```bash
cd ../api
npm install
```

### 4. Configure the Database

Create a PostgreSQL database and configure the database connection according to your backend configuration.

### 5. Start the Backend

```bash
npm start
```

### 6. Start the Frontend

Open another terminal:

```bash
cd frontend
ng serve
```

Open your browser at:

```text
http://localhost:4200
```

*Note: Adjust the folder names and startup commands according to your actual repository structure.*
